# Caregiver Support & Dashboard Module

## Core Philosophy: Support, Not Surveillance
The caregiver layer provides privacy-conscious, high-level summaries to help families and caregivers stay connected with older adults.

### Responsible AI Principles
1. **No Medical Claims**: Never diagnose depression, dementia, or cognitive disorders.
2. **No Pathologizing Language**: Avoid clinical labels or framing normal sadness/quietness as a medical disorder.
3. **Epistemic Humility**: Acknowledge when emotional cues are ambiguous or conflicting rather than presenting emotion predictions as certain facts.
4. **Data Minimization**: Media (audio/video) is processed in memory and never stored in long-term databases for caregiver review.
